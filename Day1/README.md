# File I/O example

Run the example to write and read a file with newlines:

```bash
python file_io_example.py
```

This will create `sample.txt`, append lines, and print its contents.

Profile creator example:

```bash
python profile_creator.py
```

This interactive program demonstrates multiple data types (string, int, float, boolean),
uses data structures (list and dict), and uses various operators (assignment, arithmetic,
comparison, logical, membership, identity). Comments in `profile_creator.py` indicate where
each feature is used.

Beginner (no functions) profile creator:

```bash
python profile_creator_simple.py
```

This version avoids defining any functions and implements the same features with
top-level code and comments in `profile_creator_simple.py`.
