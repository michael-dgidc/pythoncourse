# Useful Project Demo: Budget Tracker

This small Python project demonstrates a useful personal budget tracker built with only standard library modules.

## What it shows

- Decision-making with `if` / `elif` / `else`
- Built-in functions like `len()`, `sum()`, `max()`, `min()`, `sorted()`, `any()`, and `all()`
- Loops with both `for` and `while`
- Functions that group commands into reusable units
- Running a Python script from the command line
- Using standard library modules: `json`, `datetime`, `pathlib`, `statistics`, `csv`, `html`

## Files

- `budget_tracker.py`: main script with menu and user interaction
- `data_store.py`: data persistence using JSON and `pathlib`
- `reports.py`: reporting, grouping, and summary functions

## Run

```bash
python Day3/useful_project/budget_tracker.py
```
